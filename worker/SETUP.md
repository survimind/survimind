# ตั้งค่า AI วิเคราะห์ผล (Gemini + Cloudflare Worker)

ใช้ฟรีทั้งหมด ไม่ต้องผูกบัตร ทำครั้งเดียว ประมาณ 10 นาที

## ภาพรวม

```
ผู้เล่นเล่นจบ → หน้าเว็บ (GitHub Pages) → Cloudflare Worker (เก็บ key) → Google Gemini → กลับมาแสดงในหน้าผลลัพธ์
```

ผู้เล่นมองไม่เห็น API key เพราะ key อยู่ใน Cloudflare เท่านั้น

## ขั้นที่ 1: ขอ Gemini API key

1. เข้า https://aistudio.google.com แล้วล็อกอินด้วยบัญชี Google
2. กด **Get API key** → **Create API key**
3. คัดลอก key เก็บไว้ (ห้ามใส่ในไฟล์เว็บ ห้ามส่งในแชต)
4. **ห้ามผูกบัญชีชำระเงิน** จะได้อยู่ในโควตาฟรีเสมอ

## ขั้นที่ 2: สร้าง Worker

1. เข้า https://dash.cloudflare.com แล้วล็อกอิน
2. เมนูซ้ายเลือก **Workers & Pages** (หรือ **Compute → Workers**)
3. กด **Create** → เลือก **Start with Hello World!** (หรือ **Create Worker**)
4. ตั้งชื่อ เช่น `survimind-ai` แล้วกด **Deploy**
5. กด **Edit code**
6. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ `worker/worker.js` ใน repository นี้
7. กด **Deploy** มุมขวาบน

## ขั้นที่ 3: ใส่ API key

1. กลับไปหน้า Worker `survimind-ai`
2. แท็บ **Settings** → หัวข้อ **Variables and Secrets** → กด **Add**
3. Type เลือก **Secret**
4. Variable name: `GEMINI_API_KEY`
5. Value: วาง key จากขั้นที่ 1
6. กด **Deploy** (หรือ **Save**)

## ขั้นที่ 4: ทดสอบว่า Worker ทำงาน

เปิดลิงก์ Worker ในเบราว์เซอร์ (ดูได้ที่หน้า Worker เช่น `https://survimind-ai.ชื่อบัญชี.workers.dev`)
ถ้าขึ้น `{"ok":true,"service":"survimind-ai"}` แปลว่าพร้อมแล้ว

## ขั้นที่ 5: ส่งลิงก์ Worker ให้ Claude

ลิงก์ Worker ไม่ใช่ความลับ ส่งในแชตได้ Claude จะใส่ลิงก์นี้ในตัวแปร `AI_ENDPOINT` ใน `index.html` แล้วอัปโหลดขึ้น GitHub

## ตั้งค่าเพิ่มเติม (ไม่บังคับ)

| ตัวแปร | ใช้ทำอะไร | ค่าเริ่มต้น |
|---|---|---|
| `ALLOWED_ORIGINS` | เว็บที่อนุญาตให้เรียก Worker | `https://survimind.github.io` |
| `GEMINI_MODELS` | โมเดลที่ใช้ ลองตามลำดับ ถ้าตัวแรกเต็มจะใช้ตัวถัดไป | `gemini-3.5-flash-lite,gemini-3.8-flash` |

ถ้า Google เปลี่ยนชื่อโมเดลในอนาคต ให้ดูชื่อใหม่ใน Google AI Studio แล้วใส่ใน `GEMINI_MODELS`

## ความปลอดภัยและความเป็นส่วนตัว

- หน้าเว็บส่งเฉพาะคะแนนและพฤติกรรมการเล่น ไม่ส่งชื่อ รหัสนักศึกษา เพศ อายุ
- Worker สร้างคำสั่ง AI เอง จึงเอา Worker ไปใช้เป็นแชตบอตฟรีไม่ได้
- โควตาฟรีของ Gemini: Google อาจนำข้อมูลที่ส่งไปใช้พัฒนาผลิตภัณฑ์ จึงไม่ส่งข้อมูลส่วนตัวเด็ดขาด
- ถ้า AI ใช้ไม่ได้ (โควตาเต็ม เน็ตหลุด) หน้าเว็บจะแสดงผลแบบมาตรฐานแทน และมีปุ่มลองใหม่

## อัปเดตโค้ด Worker (เมื่อมีฟีเจอร์ใหม่ เช่น AI Coach)

1. Cloudflare → **Compute** → **Workers & Pages** → กด **survimind-ai**
2. กด **Edit code** (ไอคอน `</>` มุมขวาบน)
3. ลบโค้ดเดิมทั้งหมด วางโค้ดล่าสุดจาก `worker/worker.js` แล้วกด **Deploy**
4. ไม่ต้องใส่ API key ใหม่ key เดิมยังอยู่

## ให้ Worker อัปเดตเองอัตโนมัติจาก GitHub (ทำครั้งเดียว)

หลังตั้งค่านี้ ทุกครั้งที่ไฟล์ใน `worker/` บน GitHub เปลี่ยน Cloudflare จะ deploy ให้เอง ไม่ต้องคัดลอกโค้ดอีก

1. Cloudflare → **Compute** → **Workers & Pages** → กด **survimind-ai**
2. แท็บ **Settings** → หัวข้อ **Build** → กด **Connect** ที่ **Git repository**
3. เลือก **GitHub** แล้วอนุญาตให้ Cloudflare เข้าถึง repository `survimind/survimind`
4. ตั้งค่าดังนี้
   - Branch: `main`
   - Root directory (Path): `/` หรือ `/worker` ก็ได้ (มีไฟล์ wrangler.jsonc ทั้งสองที่)
   - Build command: เว้นว่าง
   - Deploy command: `npx wrangler deploy`
5. กด **Connect** แล้วรอ build แรกเสร็จ (เครื่องหมายถูกสีเขียว)

API key ไม่หาย เพราะเก็บเป็น Secret ใน Cloudflare แยกจากโค้ด


## ถ้าเปิดลิงก์ Worker แล้วเห็นหน้าเกม

แปลว่า Cloudflare deploy ไฟล์เกมทับตัวกลาง ให้ตรวจว่ามีไฟล์ `wrangler.jsonc` ที่โฟลเดอร์หลักของ repository แล้วกด **Retry deployment** ในแท็บ Deployments


## ห้องอาจารย์: เก็บผลของนักศึกษาให้อาจารย์ดู (ทำครั้งเดียว ~10 นาที)

เมื่อตั้งค่าเสร็จ ผลของนักศึกษาทุกคนที่เล่นจบจะถูกเก็บไว้ใน Cloudflare KV (ฟรี) อาจารย์เปิดดูได้ที่
`https://survimind.github.io/survimind/?teacher` → ปุ่ม **ห้องอาจารย์** → ใส่รหัสอาจารย์ → **ดูผลของนักศึกษา**

### ขั้นที่ A: สร้างที่เก็บข้อมูล (KV)
1. เข้า [dash.cloudflare.com](https://dash.cloudflare.com) → เมนูซ้าย **Storage & Databases** → **Workers KV**
2. กด **Create instance** (หรือ **Create namespace**) ตั้งชื่อ `survimind-sessions` → **Create**
3. คัดลอก **Namespace ID** (ตัวอักษรยาว 32 ตัว) แล้วส่งให้ Claude ในแชต
   ID นี้ไม่ใช่ความลับ ส่งได้ · Claude จะใส่ลงไฟล์ `wrangler.jsonc` ให้ Worker เชื่อมกับที่เก็บนี้ทุกครั้งที่ deploy

### ขั้นที่ B: ตั้งรหัสอาจารย์
1. เปิด Worker **survimind-ai** → แท็บ **Settings** → **Variables and Secrets** → **Add**
2. Type: **Secret** · Variable name: `TEACHER_KEY` · Value: รหัสที่ตั้งเอง (ยาวอย่างน้อย 8 ตัว)
3. กด **Deploy**

⚠️ อย่าส่งรหัสอาจารย์ในแชต และอย่าใส่ในไฟล์ใดบน GitHub · บอกรหัสเฉพาะอาจารย์ผู้สอน

### ขั้นที่ C: ทดสอบ
1. เล่นเกมจนจบ 1 รอบจากลิงก์ปกติ
2. เปิดลิงก์ `?teacher` → ห้องอาจารย์ → ใส่รหัส → ต้องเห็นผลรอบนั้นในตาราง

ข้อความที่อาจขึ้น
- "ยังไม่ได้เชื่อมที่เก็บข้อมูล (KV)" → ยังไม่ได้ทำขั้นที่ A หรือ Claude ยังไม่ได้ใส่ Namespace ID
- "ยังไม่ได้ตั้งรหัสอาจารย์" → ยังไม่ได้ทำขั้นที่ B
- "รหัสอาจารย์ไม่ถูกต้อง" → พิมพ์รหัสผิด

ข้อมูลที่เก็บ: เพศ อายุ สถานการณ์ ตัวละคร บุคลิก คะแนน พฤติกรรมการเล่น และชื่อ/รหัสนักศึกษาเฉพาะเมื่อผู้เล่นกรอกเองตอนบันทึกภาพผลลัพธ์ · ลบอัตโนมัติหลัง 1 ปี · โควตาฟรีของ KV เขียนได้ 1,000 ครั้งต่อวัน (ผู้เล่น 1 คนใช้ประมาณ 3–4 ครั้ง)


## บัญชีเข้าสู่ระบบทีม / อาจารย์ (ชื่อผู้ใช้ + รหัสผ่าน)

ใช้แทนลิงก์ `?editor` / `?teacher` เดิม · เข้าสู่ระบบแล้วจะได้แถบ Editor (ข้ามฉาก/ข้ามข้อ) ห้องอาจารย์ และเห็นผลของนักศึกษาโดยไม่ต้องใส่รหัสอาจารย์ซ้ำ

1. Worker **survimind-ai** → **Settings** → **Variables and Secrets** (ส่วน Runtime ด้านบน ไม่ใช่ส่วน Builds) → **Add**
2. Type: **Secret** · Variable name: `EDITOR_ACCOUNTS`
3. Value: `ชื่อผู้ใช้:รหัสผ่าน` หลายบัญชีคั่นด้วยจุลภาค เช่น `admin:รหัสยาวๆ,teacher:อีกรหัส`
   (ชื่อผู้ใช้ห้ามมี `:` · รหัสผ่านควรยาวอย่างน้อย 10 ตัว)
4. กด **Deploy**
5. หน้าแรกของเกม → ลิงก์เล็ก **สำหรับทีม / อาจารย์** → ใส่ชื่อผู้ใช้และรหัสผ่าน

- อยู่ในระบบได้ 7 วันต่อเบราว์เซอร์ · กด **ออกจากระบบ** ในห้องอาจารย์เมื่อใช้เครื่องคนอื่น
- อยากให้ทุกคนออกจากระบบทันที (เช่น รหัสหลุด) → แก้ค่า `EDITOR_ACCOUNTS` แล้ว Deploy
- อย่าส่งชื่อผู้ใช้/รหัสผ่านในแชตหรือใส่ในไฟล์บน GitHub
- เปิดหน้ามุมมองผู้เล่นจริงขณะเข้าสู่ระบบอยู่: ต่อท้ายลิงก์ด้วย `?player`

## บัญชีอาจารย์รายคน (เดโม · อยู่ใน branch `teacher-accounts`)

แยก 2 บทบาท:
- **ทีมผู้ดูแล** = บัญชีใน `EDITOR_ACCOUNTS` (เหมือนเดิม) เห็นข้อมูลทั้งหมดและมีเครื่องมือ Editor
- **อาจารย์** = บัญชีใน `TEACHER_ACCOUNTS` เห็นเฉพาะห้องเรียนที่ตัวเองสร้าง ผลและความคิดเห็นของห้องนั้น ไม่เห็นข้อมูลเว็บกลาง และไม่มีเครื่องมือ Editor

เพิ่มบัญชีอาจารย์:
1. Cloudflare → Workers & Pages → survimind-ai → Settings → Variables and Secrets → Add
2. Type = Secret · Name = `TEACHER_ACCOUNTS` · Value = `ชื่อผู้ใช้:รหัสผ่าน,ชื่อผู้ใช้2:รหัสผ่าน2` (เช่น `kru_a:รหัสที่ตั้งเอง`)
3. Deploy · อย่าส่งรหัสผ่านในแชต

หมายเหตุ: ครั้งแรกที่เพิ่ม `TEACHER_ACCOUNTS` ทุกคน (รวมทีม) จะต้องเข้าสู่ระบบใหม่หนึ่งครั้ง

### อาจารย์ขอสมัครเอง / ทีมจัดการบัญชีในเว็บ (เดโม)
- อาจารย์กด "สำหรับทีม / อาจารย์" → "อาจารย์ยังไม่มีบัญชี? ขอสมัครใช้งาน" → กรอกชื่อ คณะ ชื่อผู้ใช้ รหัสผ่าน → สถานะ "รออนุมัติ"
- ทีม (บัญชีใน `EDITOR_ACCOUNTS`) เข้าห้องอาจารย์ → ข้อ 7 บัญชีอาจารย์: อนุมัติ/ปฏิเสธ · สร้างบัญชีให้เลย (ระบบสุ่มรหัสชั่วคราว แสดงครั้งเดียว) · ปิด/เปิดใช้งาน · รีเซ็ตรหัสผ่าน · ลบ
- อาจารย์เปลี่ยนรหัสผ่านเองได้ในห้องอาจารย์ ข้อ 7 · เปลี่ยนแล้วเครื่องอื่นที่เคยเข้าสู่ระบบต้องเข้าใหม่
- รหัสผ่านเก็บแบบแฮช (PBKDF2-SHA256 + salt) ไม่เก็บรหัสจริง · บัญชีเก็บใน KV เดียวกับผลการเล่น (คีย์ `a:`)
- ต้องตั้ง `EDITOR_ACCOUNTS` ไว้เสมอ (ใช้เป็นกุญแจเซ็นการเข้าสู่ระบบ) ไม่มีแล้วระบบเข้าสู่ระบบจะปิดทั้งหมด
